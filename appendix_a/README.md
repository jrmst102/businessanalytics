# Appendix A companion files

* `Appendix_A_Quick_Reference.ipynb` — every entry as a runnable cell.
* `practice_transactions.csv` — 20 order lines, 12 orders, 8 customers,
  $1,312.00 of revenue. Shaped like StyleCraft's `transactions` table and
  small enough to hand-check. Not an assignment file.
* `practice_transactions_raw.csv` — the same file with currency-string
  prices, so the type-coercion entry has something to repair.
* `practice_customers.csv`, `practice_products.csv`,
  `practice_stores.csv` — the dimension tables the join and crosstab
  entries use.
* `command_index.csv` / `command_index.html` — the one-page index.
* `environment_record.md` — the versions the patterns were run against.
