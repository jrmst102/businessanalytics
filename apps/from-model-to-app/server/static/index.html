Explore the Mancino data, train one classroom regression model, and type inputs to get a prediction. The dataset is synthetic teaching data.

The Mancino dataset

Mancino Market is a synthetic grocery retailer: fictional daily unit sales for five stores and fifteen product categories, used throughout the course. Source: mancino_daily_sales.csv (v1_2025-11-01 snapshot, bundled offline; see data/SOURCE.md).
